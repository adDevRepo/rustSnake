# Snake Game in Rust 🐍

Petit projet personnel pour apprendre le langage Rust en développant un jeu Snake.

## Technologies

- Rust
- Cargo
- Macroquad
- RustRover

## Installation

Cloner le projet :

```bash
git clone git@github.com:adDevRepo/rustSnake.git
cd snake_game
```

## Lancer le projet

```bash
cargo run
```

## Build

```bash
cargo build
```

## Dépendances

Le projet utilise :

- macroquad

## Fonctionnalités prévues

- Déplacement du snake
- Gestion des pommes
- Score
- Collision avec les murs
- Game Over
- Augmentation progressive de la vitesse
